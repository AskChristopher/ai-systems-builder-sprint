## What I Learned

- Small output-format details matter in coding challenges, such as using `Hello, [name]` with a comma instead of a colon.

- Practiced casting and type handling with `int()`, `float()`, `bool()`, and `str()`.
- Confirmed type behavior differences: string addition concatenates (`"5" + "5" = "55"`) while numeric addition computes (`5 + 5 = 10`).
- Learned to use Power Automate test logs and expressions to diagnose and fix workflow errors.
- Learned that many automation issues came from schema alignment and column mapping.
- Understood the architecture insight that `CLAUDE.md` + skills + subagents + hooks + MCP servers creates a designed development environment.

## Problems I Encountered

- Ran into several schema-related failures in the automation flow.
- At first, the summary was not writing into the SharePoint file.

## Biggest Insight

- Reliable AI outputs depend on clean structure: if schema, mapping, and expression logic are not aligned, the pipeline appears to work but the prompt layer can still fail.
