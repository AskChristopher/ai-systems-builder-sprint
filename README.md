# AI Systems Builder

> An open-ended, project-based learning system for becoming an AI Systems Builder.

## Mission

This repository is my AI Systems Builder learning and competency hub. It documents progress toward becoming an AI engineer through project-based learning, skill evidence, experiments, and milestone reflection.

Rather than collecting certificates or maintaining daily entries for consistency, I demonstrate progress through things I build, skills I demonstrate, experiments I run, and reflections at meaningful milestones.

## How Progress Is Demonstrated

- **Projects:** what was built, including links to external repositories where applicable, with architecture decisions and completion evidence.
- **Skills:** demonstrated competency tracked in `docs/Python-Roadmap.md`, `docs/AI-Roadmap.md`, and `assets/progress.md`.
- **Experiments / Evaluations:** tests run, evaluation criteria, failure cases, and trade-offs observed.
- **Milestone reviews:** reflections at meaningful checkpoints using `templates/milestone-review.md`.

## Project Records

`projects/` contains project records for this hub, not duplicate copies of external codebases. When a project lives in its own repository, the record here documents what was built, skills demonstrated, experiments/evaluations performed, lessons learned, and evidence of completion, with links to the external repository, demo, and docs.

Use `templates/project-README.md` for new project records.

## Repository Structure

- `projects/` — Current project records and links to external repositories.
- `docs/` — Learning method, roadmaps, and review templates.
- `assets/` — Python and AI engineering knowledge base and practice artifacts.
- `daily/` — Historical archive. Daily logging is no longer maintained. Entries are preserved as-is for reference and are not continued.
- `weekly/` — Historical weekly reviews and milestone reflections.
- `notes/` — Working notes and future project backlog.
- `templates/` — `project-README.md` for project records and `milestone-review.md` for milestone reflection.
